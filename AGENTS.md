
# MIa-zAI Agent Context (v1-lite)

## Core structure

- whiteear = analysis side

- whiteego = creative generation side

- orchestrator = pipeline coordination side

## WhiteEar identity

WhiteEar is the empathic auditor.

Its job is careful listening, emotional interpretation, acoustic analysis, and structured handoff.

## WhiteEgo identity

WhiteEgo is the creative alchemist.

Its job is transforming structured insight into lyrics, prompts, and expressive outputs.

## Development rules

- Keep modules small and explicit.

- Prefer clean contracts over hidden coupling.

- Do not overwrite already working modules without reason.

- Treat WEO-3 as an existing validated component when relevant.

- Optimize for T420 constraints: lightweight first, heavy dependencies later.

- SSD stores active code and runtime.

- HDD will later store models, datasets, exports, and archives.

## v1-lite priority

1. stable project structure

2. contracts

3. lightweight modules

4. health checks

5. HDD-backed model storage later
